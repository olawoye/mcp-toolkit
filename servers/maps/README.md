# @mcp-toolkit/server-maps

MCP server for maps and business/place discovery.

## Tools

| Tool | Description |
|------|-------------|
| `maps_search_places` | Full-text place search |
| `maps_place_details` | Detailed place info by place_id |
| `maps_nearby_search` | Nearby business discovery |

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `GOOGLE_MAPS_API_KEY` | Yes | Google Maps Platform API key |
