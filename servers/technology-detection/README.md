# @mcp-toolkit/server-technology-detection

MCP server for website technology stack detection via BuiltWith.

## Tools

| Tool | Description |
|------|-------------|
| `detect_technologies` | List technologies used by a domain |

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `BUILTWITH_API_KEY` | Yes | BuiltWith API key |
