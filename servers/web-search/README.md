# @mcp-toolkit/server-web-search

MCP server exposing web search capabilities.

## Tools

| Tool | Description |
|------|-------------|
| `web_search` | Full-web search via Google Custom Search or Bing |
| `web_news_search` | News-specific search |

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `GOOGLE_SEARCH_API_KEY` | For Google | Google Custom Search API key |
| `GOOGLE_SEARCH_CX` | For Google | Custom Search Engine ID |
| `BING_SEARCH_API_KEY` | For Bing | Bing Web Search API key |
